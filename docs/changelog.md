## v0.2.0 · 2026-10-17

应用版本与网站部署独立，是否上线以实际发布记录为准。

### 新增

- 本地图文管理：从一个或多个日期的已保存精选中选图，不影响原来的精选和公开设置。
- 图片拖拽排序、独立滤镜和强度、九宫格预设，以及组内大图直接调色。
- 时间和城市自动填写或手动调整，独立地点参考，可选文案标题及正文。
- 可读的“日期_城市_标题”目录、按顺序命名的成品照片和可直接复制的 `文案.txt`。
- 独立的“准备文案”任务文件与 Agent 指令，不自动调用模型或上传图片。
- 图文模块、版本一致性和隔离桌面浏览器回归测试。

### 修复

- 切换或重新载入图文组期间暂停编辑，读取失败保留原草稿；保存直接采用返回数据，避免后续读取失败时重复新建。
- 显式关闭 SQLite 连接，避免 Windows 导出时临时数据库被占用而无法清理。
- 大图强度滑条的方向键不再误切图片，焦点循环包含输入控件。

### 兼容与隐私

- 公开数据和图文清单仍使用v1；旧图文滤镜保持兼容，旧hash目录在下次保存时转换为可读命名。
- 图文清单使用原子保存、ETag冲突检查和独立图片快照，删除进入本地回收目录。
- 原图、数据库、配置、图文内容、缓存和导出继续被Git忽略，图文组不进入公开产物。
- 本次应用升级不创建数据Release、不部署Pages，也不改变已有公开网站。
